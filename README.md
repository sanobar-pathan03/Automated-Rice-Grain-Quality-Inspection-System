**Core Capabilities:**
* **Automated Segmentation:** Isolates individual grains from complex backgrounds using advanced image processing.
* **Quantitative Feature Extraction:** Calculates precise morphological data (Area, Perimeter, Aspect Ratio) and color profiles.
* **Intelligent Classification:** Utilizes Machine Learning to accurately categorize grains as Whole, Broken, or Defective.

## 📖 About The Project

Rice is a globally consumed staple food, and its quality directly impacts market value and consumer satisfaction. Traditionally, rice inspection relies on manual visual checks by human operators. This manual method is highly time-consuming, subjective, and prone to human error due to visual fatigue. Furthermore, it is difficult to maintain consistency when inspecting large quantities of grains.

To overcome these limitations, this project proposes an **Automated Rice Grain Quality Inspection System**. By leveraging **Computer Vision (OpenCV)** and **Machine Learning (Scikit-Learn)**, the system automatically captures, processes, and classifies rice grains into three distinct categories:
* 🟢 **Whole Grains:** Intact, premium quality grains with no visible damage.
* 🟠 **Broken Grains:** Partially broken or smaller pieces resulting from milling.
* 🔴 **Defective Grains:** Discolored, damaged, or abnormal grains.

## ✨ Key Features

* **Automated Detection:** Instantly isolates individual rice grains from the background using contour detection.
* **Advanced Feature Extraction:** Calculates precise geometric (Area, Perimeter, Aspect Ratio) and color (BGR) features.
* **Machine Learning Classification:** Uses a Random Forest Classifier for highly accurate and consistent categorization.
* **Interactive Web UI:** A clean, aesthetic dashboard built with Streamlit for easy image uploading and real-time result visualization.
* **Quantitative Results:** Provides exact numerical data alongside visual predictions, eliminating subjective guesswork.

## ⚙️ Methodology & Pipeline

The system follows a robust, standard image processing pipeline as outlined in the project case study:

1. **Image Acquisition:** Capturing high-resolution digital images of rice grains.
2. **Pre-processing:** Converting images to grayscale, applying Gaussian blur to reduce noise, and using Thresholding to separate grains from the background.
3. **Segmentation:** Utilizing morphological operations (Opening/Closing) and contour detection to isolate individual grains.
4. **Feature Extraction:** Extracting critical parameters for each grain:
   * *Geometric:* Area, Perimeter, Length, Width, Aspect Ratio.
   * *Color:* Average BGR pixel values.
5. **Classification:** Feeding the extracted features into a trained Random Forest Classifier to predict the grain's quality.
